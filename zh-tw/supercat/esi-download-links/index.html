ESI 下載來源

SuperCAT 主站上各家 EtherCAT slave 的官方 ESI(裝置描述 XML)下載來源清單。優先使用「與韌體版號相符的官方檔」,不要手動改 XML —— 這樣才能避免 -1014 設備認不到的問題。

最後更新:2026-07-06

ESI 怎麼安裝、怎麼重掃(以及 -1014 解法),見 匯流排建置:掃描、ESI 與設備識別。

泓格 ICP DAS ECAT-2000 系列(含 ECAT-2055) ECAT-2000 系列合一 XML V1.10 2026-07-06 單一檔含整個 ECAT-2000 系列;FTP 目錄

之後會陸續補上更多廠牌。

檔案放哪

在 PCIe-833x SuperCAT 環境,把下載的 ESI/XML 放到:

E:\Program Files (x86)\ADLINK\PCIe-833x\EtherCAT\EtherCAT

Scan 成功後,產生的拓樸 XML(ENI)會出現在 …\EtherCAT\ENI。寫入 Program Files (x86) 需要 Windows 管理員(UAC)權限;加檔後重新掃描／重建 cache。

點任意處或按 Esc 關閉
