如何燒錄 image？

本頁說明如何在 NEON 相機上燒錄新的作業系統。

Neon-2000-JNX（Jetson Xavier NX）
  • 要燒錄：內建 eMMC + microSD 卡
  • 步驟：1 → 2 → 3 → 4
  • 產品頁 / EOS-JNX
Neon-2000-ONO（Jetson Orin Nano）
  • 要燒錄：內建 eMMC
  • 步驟：1 → 3 → 4
  • 不確定系統是跑在 eMMC 還是 microSD 卡？請看 如何確認開機裝置？
  • 各機型 NVIDIA 支援的最高版本：JetPack 支援版本
  • 查詢 NEON 目前的版本：head -n1 /etc/nv_tegra_release

需要準備：

  • 一台裝 Ubuntu 的電腦，用 microUSB 連接 NEON 進行燒錄
  • microUSB 傳輸線
  • 短路帽（jumper）2 個，NEON 隨貨附
  • 僅 JNX：32GB 以上的 microSD 卡和讀卡機

  • Windows：certutil -hashfile <檔案> MD5

步驟 2：燒錄 microSD 卡

Neon-2000-JNX
  1. 解壓縮 microSD 檔案，取得 .img 檔：tar -zxvf <檔案>
  2. 把 .img 寫入 microSD 卡
    • Ubuntu：sudo dd if=<image file>.img of=/dev/sdX bs=4M conv=fsync，或「磁碟」（Disks）工具（影片）
    • Windows：Win32 Disk Imager
    • Linux、macOS 或 Windows：Balena Etcher
  3. 把 microSD 卡插入 NEON

請使用高品質的 microSD 卡，避免資料損毀。

Neon-2000-ONO
不需要，直接到步驟 3。

步驟 3：進入恢復模式（recovery mode）

  1. NEON 接上電源開機
  2. 短路 pin 5 和 6（RECOVERY，綠框），這個短路帽一直插著，直到燒錄完成
  3. 短路 pin 3 和 4（RESET，橙框）約 2 秒，電源燈熄滅後拔掉這個短路帽，電源燈會再亮起
  4. 用 microUSB 線連接 NEON 和電腦

步驟 4：燒錄 eMMC

先在電腦上執行 lsusb，清單中出現 Nvidia Corp. = NEON 已進入恢復模式，可以燒錄。

接著解壓縮 eMMC image，進入資料夾，執行燒錄指令。 燒錄期間請勿拔除 microUSB 線或電源。

Neon-2000-JNX
解壓縮：tar -zxvf <檔案>

JetPack 解壓後的資料夾 燒錄指令 看到這個代表完成

Neon-2000-ONO
解壓縮：sudo tar -I lbzip2 -xf <檔案>

JetPack 解壓後的資料夾 燒錄指令 看到這個代表完成
6.2 / 6.1 / 5.1.2 mfi_jetson-orin-nano-neon2000-ono_4-<L4T>-rel.<版本>
（沒有 _release 字尾）		 sudo ./tools/kernel_flash/l4t_initrd_flash.sh --flash-only --massflash 15 --network usb0 Flash complete (SUCCESS)

完成後：關閉 NEON 電源，拔掉 pin 5-6 的短路帽，（JNX）確認已插入步驟 2 的 microSD 卡，再開機。 確認版本：head -n1 /etc/nv_tegra_release

附錄：備份與還原 JNX eMMC

  • 方法 1

    1. 在 Linux x86 Ubuntu 電腦下載環境：https://sftp.adlinktech.com/image/Neon-JNX/deploy.neonjnx.tar.gz（MD5: d9e7e4ff4030f7d81f72c353aad6d272）
    2. tar -zxvf deploy.neonjnx.tar.gz
    3. sudo ./flash.sh -r -k APP -G backup.img <board 名稱> mmcblk0p1
      • HW A3：jetson-neonjnx-a3-emmc
      • HW A2：jetson-xavier-nx-neonjnx-emmc

  • 方法 2

    • 備份
    cd ~/
mkdir mntTemp
sudo mount /dev/mmcblk0p1 mntTemp
cd mntTemp
sudo tar -jcf ../customerEMMC.tbz2 *
sync
cd ../
sudo umount mntTemp
rmdir mntTemp
    • 還原
    cd ~/
mkdir mntTemp
sudo mount /dev/mmcblk0p1 mntTemp
sudo tar jxf customerEMMC.tbz2 -C mntTemp
sync
sudo umount mntTemp
rmdir mntTemp
點任意處或按 Esc 關閉
