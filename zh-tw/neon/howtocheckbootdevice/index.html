如何確認開機裝置（eMMC 或 microSD）？

NEON-2000-JNX 有兩個儲存裝置：

儲存裝置 Linux 裝置名稱 存放內容
內建 eMMC（在 Jetson 模組上） /dev/mmcblk0 bootloader 和 kernel。內建 eMMC 容量有限。
microSD 卡 /dev/mmcblk1 作業系統（Ubuntu）和 JetPack（NEON-2000-JNX 標準 image）

NEON 一律從內建 eMMC 啟動，作業系統（根目錄 /）則可能跑在 eMMC 或 microSD 卡上。升級或備份 NEON 之前，請先確認系統跑在哪裡。

裝置名稱後面的 p1、p2… 是分割區編號，例如 /dev/mmcblk1p1 = microSD 卡的第 1 個分割區。

步驟 1：查看掛載為 / 的裝置

在 NEON 上開終端機，執行：

df -h /

輸出範例：

Filesystem      Size  Used Avail Use% Mounted on
/dev/mmcblk1p1   59G   21G   36G  37% /

步驟 2：判讀結果

第一欄（Filesystem） 系統跑在 下一步
/dev/mmcblk1p1 microSD 卡 1. 備份：microSD 卡、eMMC
2. 升級：如何燒錄 image？
/dev/mmcblk0p1 內建 eMMC 升級前請先聯絡 ADLINK 技術支援。

選用：列出所有儲存裝置

lsblk

MOUNTPOINT 欄位是 / 的那一行，就是系統目前跑的裝置。

點任意處或按 Esc 關閉
