How to flash image?

This page covers how to flash a new operating system onto a NEON camera.

Neon-2000-JNX (Jetson Xavier NX)
  • Storage to flash: internal eMMC + microSD card
  • Steps: 1 → 2 → 3 → 4
  • Product page / EOS-JNX
Neon-2000-ONO (Jetson Orin Nano)
  • Storage to flash: internal eMMC
  • Steps: 1 → 3 → 4
  • Not sure whether your system runs from the eMMC or the microSD card? See How to check the boot device?
  • Highest version supported by NVIDIA for each model: JetPack support matrix
  • Check your current version on the NEON: head -n1 /etc/nv_tegra_release

Requirements:

  • A PC with Ubuntu, to flash the NEON over microUSB
  • microUSB cable
  • 2 pin jumpers, included with the NEON
  • JNX only: microSD card of at least 32GB and a card reader

Check the MD5

Make sure the downloaded file is complete. The result must match the MD5 above.

  • Linux: md5sum <file>
  • Windows: certutil -hashfile <file> MD5

Step 2: Flash the microSD card

Neon-2000-JNX
  1. Unzip the microSD file to get a .img file: tar -zxvf <file>
  2. Write the .img file to the microSD card
    • Ubuntu: sudo dd if=<image file>.img of=/dev/sdX bs=4M conv=fsync, or Disks (video)
    • Windows: Win32 Disk Imager
    • Linux, macOS or Windows: Balena Etcher
  3. Insert the microSD card into the NEON

Use a high quality microSD card to prevent corruption.

Neon-2000-ONO
Not needed. Go to Step 3.

Step 3: Enter recovery mode

  1. Power on the NEON
  2. Short pins 5 and 6 (RECOVERY, green box) and keep this jumper on until flashing is complete
  3. Short pins 3 and 4 (RESET, orange box) for 2 seconds until the power LED goes out, then remove this jumper. The power LED lights up again
  4. Connect the microUSB cable to the NEON and the host PC

Video:

Step 4: Flash the eMMC

First, run lsusb on the host PC. Nvidia Corp. in the list = the NEON is in recovery mode and ready to flash.

Then unzip the eMMC image, go to the folder and run the flash command. Do not unplug the microUSB cable or the power while flashing.

Appendix: Back up and restore the JNX eMMC

  • Method 1

    1. Download the environment on a Linux x86 Ubuntu PC: https://sftp.adlinktech.com/image/Neon-JNX/deploy.neonjnx.tar.gz (MD5: d9e7e4ff4030f7d81f72c353aad6d272)
    2. tar -zxvf deploy.neonjnx.tar.gz
    3. sudo ./flash.sh -r -k APP -G backup.img <board name> mmcblk0p1
      • HW A3: jetson-neonjnx-a3-emmc
      • HW A2: jetson-xavier-nx-neonjnx-emmc

  • Method 2

    • Back up
    cd ~/
mkdir mntTemp
sudo mount /dev/mmcblk0p1 mntTemp
cd mntTemp
sudo tar -jcf ../customerEMMC.tbz2 *
sync
cd ../
sudo umount mntTemp
rmdir mntTemp
    • Restore
    cd ~/
mkdir mntTemp
sudo mount /dev/mmcblk0p1 mntTemp
sudo tar jxf customerEMMC.tbz2 -C mntTemp
sync
sudo umount mntTemp
rmdir mntTemp
