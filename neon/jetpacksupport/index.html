JetPack support matrix

Which JetPack / Jetson Linux (L4T) versions can run on your NEON? The upper limit is set by NVIDIA for each Jetson module. ADLINK provides images for the versions marked ✔.

Summary

Model Jetson module Latest version supported by NVIDIA Latest ADLINK image
Neon-2000-JNX Jetson Xavier NX JetPack 5.1.8 (L4T 35.7.0)

Neon-2000-ONO Jetson Orin Nano JetPack 7.2.1 (L4T 39.2.1) JetPack 6.2 (L4T 36.4.3)
